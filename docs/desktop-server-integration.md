# 桌面端服务器接入与验收

2026-10-23，北京时间。服务器 API：`http://10.60.150.179:8000/api`。

## 使用

运行仓库根目录 `run_desktop_server.bat` 或 `run_desktop.bat`，先登录账号，再在工作台左侧“检测后端”下拉框选择本地或服务器。切换不退出工作台；地址在登录后的“系统设置 → 服务连接”中编辑并应用。启动脚本可设置初始模式，实际选择仍可在工作台中修改。

账号入口使用服务器的真实注册、登录接口，密码至少 12 位，与检测后端选择分开。登录后即使上次选择的本地服务没有启动，也能进入工作台切换服务器。切换到需要独立账号的后端时，在工作台内弹出目标后端登录窗口；旧版无认证本地后端无需额外登录。

地址和开关保存在 `%LOCALAPPDATA%\AIassist\backend.json`；令牌只驻留进程内，重启需要重新登录。`AIASSIST_BACKEND_URL` 可覆盖启动时的服务器地址。支持 SSH 隧道地址，例如 `http://127.0.0.1:18000/api`。

业务请求、上传、下载、完整性导出与 WebView2 原文预览统一携带 Bearer 认证。401 清除当前后端会话，保留工作台，可点击“重新连接”或切换后端，不会自动重提任务。切换前验证目标健康和认证，失败或取消保留原连接；切换成功后清除项目、规则、结果及预览状态。任务执行中禁止切换。会话按 API 地址分别保存在内存中，退出时尝试撤销所有已连接会话，204 不进行 JSON 解析。

服务器模型在服务器端配置。本机模型设置只影响本机环境，不能修改服务器模型。

## 复现

```powershell
dotnet build desktop-wpf/AiReportDesktop.csproj -c Release
dotnet run --project scripts/desktop_connection_smoke/ConnectionSmoke.csproj
python scripts/verify_server_modules.py
```

Python 脚本需要 `requests` 和 `python-docx`。复现会创建临时账号和独立项目，调用服务器模型并消耗少量额度；结束后删除自己创建的项目并退出。不得把服务器全部通过条件改成只看任务创建的 HTTP 200。
