# 在客户端接收服务器审查记录

管理员将审查记录分发给指定服务器账号后，该账号可以在桌面客户端领取记录和原始报告，并保存到本机后端。接收过程保留已有审查结果，无须重新运行审查。

## 启动本地后端

在项目目录运行：

```powershell
cd D:\AIassist
.\run_backend.bat
```

保持后端运行，再启动桌面客户端。本地服务默认地址为 `http://127.0.0.1:8000/api`。打开“服务器收件箱”不会自动启动本地服务；如果服务已在后台运行，无须重复启动。

没有自定义环境变量时，本地审查结果、原始报告和接收记录保存到项目目录下的 `.runtime\app.db`，本机为 `D:\AIassist\.runtime\app.db`。关闭客户端或重启电脑后数据仍保留；再次查看时需要运行本地后端。

启动脚本固定使用本地模式，并保留显式设置的 `AIASSIST_DATA_DIR` 和 `DATABASE_URL`。`DATABASE_URL` 优先；只设置 `AIASSIST_DATA_DIR` 时，数据库位于该目录的 `app.db`。例如：

```powershell
$env:AIASSIST_DATA_DIR = 'E:\AIassistData'
.\run_backend.bat
```

此示例适用于当前进程没有设置 `DATABASE_URL` 的情况。后端从进程环境读取配置，不会自动加载 `.env` 文件。

旧启动脚本曾使用 `%TEMP%\AIassist\app.db`。新版不会自动复制、合并或覆盖旧数据库；如需使用已有的自定义数据库，应明确设置其目录或连接地址。

## 登录服务器和本地账号

1. 登录桌面客户端，在“审查记录”页面点击“服务器收件箱”。
2. 在“服务器账号”卡片中确认服务器地址，输入管理员分发记录所对应的账号和密码，点击“登录服务器”。默认地址为 `http://10.60.150.179:8000/api`。
3. 在“保存到本机”卡片中确认本地地址，使用本地账号点击“登录本地”。如果主界面已经登录该本地后端，收件窗口会复用当前会话。
4. 第一次使用本地账号时，点击“注册本地账号”，填写展开的确认密码，再次点击“注册本地账号”。

服务器与本地后端使用各自的账号和登录会话。服务器账号存在，并不表示本地已经有同名账号。本机旧版本数据库原本没有用户表和账号，首次启动新版后需要注册本地账号。

## 保存和查看记录

1. 在收件箱选择“待接收”“已接收”或“全部”，点击“刷新收件箱”。记录较多时使用“上一页”“下一页”。
2. 选择一条记录，点击“保存到本地”。客户端先下载并校验记录，再写入本地数据库；保存成功后才向服务器确认接收。
3. 显示“已保存并确认”时，表示本地保存和服务器确认均已完成。
4. 点击“查看本地记录”，主界面将切换到本地后端的审查记录，可继续查看项目、报告、审查意见及原文定位。
5. 需要将原始报告另存为普通文件时，在审查详情中使用“原始报告另存”，选择保存位置。该文件副本与本地数据库中的报告快照分别保存。

服务器上的“已接收”表示该账号曾确认接收，不代表当前电脑一定已有副本。换电脑后，可在“已接收”或“全部”中选择记录，再次保存到当前电脑。对同一本地账号重复接收同一条分发记录，不会重复创建项目。

## 传输中断或状态异常

| 界面情况 | 处理方式 |
| --- | --- |
| 无法连接本地后端 | 先运行 `run_backend.bat`，确认本地地址，然后重试本地登录。 |
| 本地账号登录失败 | 确认使用的是本地账号；首次使用需要注册。 |
| 收件箱为空 | 检查登录的服务器账号、筛选条件，并确认管理员已向该账号分发记录。 |
| 已保存待确认 | 数据已经保存在本地。网络恢复后，对同一条记录再次点击“保存到本地”即可补确认；也可先查看本地记录。 |
| 登录已过期 | 按界面提示重新登录对应后端，再刷新或重试接收。 |
| 分发已撤回 | 该记录不能继续从服务器领取；需要管理员重新分发。已经保存到本机的副本会保留。 |
| 取消或中断传输 | 已经保存成功的记录会保留。重新选择该记录并保存，可继续确认完成状态。 |

备份本地记录时，需要备份实际使用的 `app.db`；仅保存另外下载的原始报告，不包含审查意见和接收记录。
